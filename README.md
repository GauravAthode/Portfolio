# Gaurav Athode Portfolio

This repository contains a React portfolio application. The React application remains inside `frontend/`; `backend/` is retained as an empty placeholder for possible future use.

## Run locally

```text
cd frontend
npm install
npm start
```

The development server opens the portfolio at the local URL shown by CRA.

## Production build

```text
cd frontend
npm run build
```

The generated production files are written to `frontend/build/`.

## Contact behavior

The contact form validates the entered details in the browser and opens the visitor's default email application with a prefilled message. The site does not send or store form submissions.
